🚀 The Dubai Mall — Interactive Frontend Experience

This project is an interactive, high-end presentation of The Dubai Mall, designed to feel more like a product experience than a traditional slide deck.

Instead of static slides, the goal was to create a fluid, immersive UI with smooth transitions, motion effects, and multiple navigation methods.

🔗 Live Project
Live Demo: https://willowy-salmiakki-c67764.netlify.app/
GitHub Repo: https://github.com/Alpha9903/Dubai-mall-presentation-
🎯 What I Focused On
Turning a basic presentation into an interactive experience
Making navigation intuitive across keyboard, mouse, and touch
Using animation to enhance storytelling, not distract from it
Keeping the architecture modular and scalable
⚙️ Tech Stack
React 19 – Component-based architecture
Vite – Fast build and dev environment
Tailwind CSS – Rapid and consistent styling
Framer Motion – Animations and transitions
Lucide React – Icons
✨ Key Features
1. Video Intro Experience
Fullscreen intro video with overlay effects
Custom “Start” interaction to enter presentation
2. Animated Slide System
Smooth transitions between slides using Framer Motion
Each slide designed as a reusable component
3. Multiple Navigation Methods
Keyboard (arrow keys, spacebar)
Swipe gestures (mobile)
Clickable navigation dots
Mini-map overlay (press M)
4. Advanced UI Interactions
Parallax effects based on cursor movement
Animated counters and transitions
Hover-based micro-interactions
5. Custom Cursor
Physics-based animated cursor (desktop only)
Automatically disabled on touch devices
🧠 Architecture Approach
Each slide is a separate component, making the system easy to scale
Animations are handled centrally for consistency
Designed with performance in mind (no heavy blocking effects)
🤖 AI + Creative Workflow

I used AI tools as part of the development process:

Assisted with structuring components and debugging
Helped generate initial content ideas
Created and edited the intro video used in the experience

The goal was not just to use AI—but to integrate it effectively into a real workflow.
